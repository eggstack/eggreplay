## CI matrix

Keep Linux stable + Rust 1.89 MSRV qualification and add stable build/test coverage for macOS and Windows unless a concrete dependency limitation is found.

Use `--locked` in CI after the lockfile is updated. If platform-specific network tests cannot run uniformly, separate portable unit/contract tests from Linux-only transport qualification and document the support implication rather than silently claiming all three platforms.

Add a dedicated minimum-feature/dependency-boundary check proving:

- core/store do not pull EggFetch/EggServe/Eggress;
- direct HTTP build does not require Eggress routing;
- the CLI Eggress route grammar enables only the intended narrow feature set.

## Documentation truth pass

Correct stale or overbroad claims, including:

- README status must no longer say implementation is still being delivered once corrective closure is complete;
- docs must distinguish tested/supported HTTP/1.1 from deferred H2/H3;
- redaction docs must state opaque-body limitations;

- lazy replay: fixture aggregate payload substantially larger than active-stream memory model;

- large-body chunking remains bounded;
- matcher near-miss work stays bounded by configured candidate limits.
